# Indonesia market routing

## Geographic order

1. Jakarta, Tangerang Selatan, Tangerang, BSD, and Jabodetabek hybrid/on-site.
2. Indonesia-wide remote roles.
3. Overseas roles explicitly open to remote workers based in Indonesia.
4. Overseas on-site roles only when visa sponsorship is explicit.

Do not equate “remote” with globally eligible. Check country restrictions and
work-authorization language in the official posting.

## Source order

1. JobStreet Indonesia and Glints Indonesia through `portals.yml` providers.
2. Official career pages for Indonesian target companies.
3. Dealls, Kalibrr, LinkedIn Jobs, KitaLulus, and public web results.
4. Supported ATS sources for Xendit, Ninja Van, remote-first employers, and
   international AI companies.
5. Curated international internship aggregators only after confirming the
   original employer posting and Indonesia eligibility.

Source availability and platform behavior change. Verify them during each hunt;
do not rely on this list as proof that a posting is current.

## Search vocabulary

Rotate both Indonesian and English terms:

- `magang AI`, `AI Engineer Intern`, `AI Automation Intern`
- `LLM Engineer Intern`, `Generative AI Intern`, `Applied AI Intern`
- `Machine Learning Intern`, `Data Scientist Intern`
- `Software Engineer Intern AI`, `Product Engineer Intern AI`
- `Business Analyst Intern AI`, `automation intern`

Applied LLM, agentic workflow, RAG, tool-calling, AI automation, and AI-enabled
full-stack roles are stronger fits than research-heavy model-training roles.

## Minimum evidence per lead

Record the official URL, company, role, location/work model, posted date when
available, compensation only when stated, internship evidence, eligibility risk,
and a concise fit reason. Mark missing fields as unknown rather than inferring.

## User-specific policy

Load candidate facts and preferences only from the active checkout's user layer:
`cv.md`, `config/profile.yml`, `modes/_profile.md`, `modes/_brief.md`,
`modes/_custom.md`, `data/blacklist.md`, and the tracker. These paths vary by
installation and must be resolved through `PROJECT_ROOT`; never embed a local
Windows path in this skill.

Salary floors, seniority, sector exclusions, target cities, work authorization,
and language are user policy—not universal Indonesia/Asia rules. Mark unknown
fields as unknown and do not copy personal contact details into hunt summaries.
